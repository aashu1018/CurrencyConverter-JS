A simple and responsive web application that allows users to convert an amount from one currency to another using real-time exchange rates. Built using HTML, CSS, and JavaScript.

🚀 Features
🔄 Real-time currency conversion

🌐 Supports multiple currencies

📱 Responsive design for mobile and desktop

💡 Clean and intuitive user interface


⚙️ How It Works
1. User selects the source and target currencies.
2. Inputs an amount.
3. JavaScript fetches the latest exchange rate from the API.
4. The converted amount is displayed instantly.
